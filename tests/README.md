# Тестування і заміри (розділ 3)

Усі команди запускати з кореня репозиторію (там, де `main.py`), тим самим Python, що й бота:

```powershell
& 'C:\Program Files\Python312\python.exe' tests\test_scenarios.py
```

Результати зберігаються в `tests/results/*.csv` (відкриваються в Excel, роздільник `;`).
Робоча база `database.db` жодним скриптом не змінюється — для кожного заміру створюється тимчасова.

| Скрипт | Що вимірює | Інтернет | Куди в курсову |
|---|---|---|---|
| `test_scenarios.py` | 22 сценарії користувача (доступ, розклад, ДЗ, конфлікти, видалення, розсилки) з імітацією Telegram | не потрібен | 3.3, таблиця результатів тестування |
| `bench_parser.py` | час запитів до АСУ «ВНЗ», перетворення відповіді, запису в БД, повного циклу оновлення | потрібен | 3.2 |
| `bench_ai.py` | час і точність розпізнавання розкладу Gemini за зразками з `tests/samples` | потрібен | 3.2 |
| `bench_db.py` | час основних запитів до БД з індексами і без, план запиту | не потрібен | 3.2 |
| `log_stats.py` | час обробки повідомлень реальним ботом за його журналом | — | 3.2 |

## Порядок запуску

1. `tests\test_scenarios.py` — має бути «Пройдено 22 з 22».
2. `tests\bench_db.py` (можна більше даних: `--groups 50 --days 180`).
3. `tests\bench_parser.py --runs 10` — паузи між запитами вже є, щоб не навантажувати сервер.
4. `tests\bench_ai.py --runs 3`
   - Зразки кладуться в `tests/samples`: фото (`назва.jpg`), альбом (папка `назва/` з кількома фото) або текст (`назва.txt`).
   - Еталон — файл `назва.expected.json` (приклад: `text_week.expected.json`).
   - Для знімків екрана розкладу з АСУ «ВНЗ» еталон можна не писати вручну: `--api` візьме його з сервера за ті самі дати.
   - Якщо на фото немає викладачів чи аудиторій, оцінюй лише видимі поля: `--fields end_time,subject,type`.
   - Детальний перелік помилок — `tests/results/ai_errors.txt`.
5. Журнал бота:
   ```powershell
   & 'C:\Program Files\Python312\python.exe' main.py 2>&1 | Tee-Object -FilePath bot.log
   ```
   Попрацювати з ботом, зупинити (Ctrl+C), потім `tests\log_stats.py bot.log`.

## Опис методики для тексту

- Час вимірювався функцією `time.perf_counter()`; для кожної операції наведено середнє, медіану й максимум.
- Точність розпізнавання: заняття вважається знайденим, якщо збігаються дата, час початку і підгрупа;
  для знайдених занять порівнюються поля (час завершення, назва, тип, аудиторія, викладач) після нормалізації
  (регістр, пробіли, апострофи, запис аудиторії).
- Функціональні тести запускають справжні обробники бота (aiogram `Dispatcher.feed_update`),
  а відповіді Telegram, АСУ «ВНЗ» і Gemini імітуються, тому результати відтворювані.
